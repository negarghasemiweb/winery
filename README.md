🇬🇧 English

📌 About the Project

Winery is a wine-themed website that presents a collection of wine products through an elegant and visually appealing layout. It includes product showcases, newsletter subscription sections, vineyard tour information, and recent wine-related articles.

✨ Features

- Hero Section: A welcoming introduction featuring fine wines.
- Featured Products: Showcases selected wine products and their prices.
- Wine Categories: Displays different wine collections.
- Newsletter Subscription: Allows visitors to sign up for wine news and special offers.
- Vineyard Tours: Introduces visitors to the winemaking process and vineyard experiences.
- Recent Articles: Features wine-related news, history, and food pairings.
- Navigation Menu: Provides access to the website's main sections.
- Responsive Design: Designed to provide a user-friendly browsing experience.

📌 درباره پروژه

واینری یک وب‌سایت با موضوع شراب است که مجموعه‌ای از محصولات را با طراحی زیبا و جذاب به نمایش می‌گذارد. این وب‌سایت شامل معرفی محصولات منتخب، بخش عضویت در خبرنامه، اطلاعات مربوط به تورهای تاکستان و مقالات مرتبط با دنیای شراب است.

✨ امکانات

- بخش اصلی (Hero Section): معرفی اولیه وب‌سایت و نمایش شراب‌های منتخب.
- محصولات ویژه: نمایش محصولات منتخب به همراه قیمت آن‌ها.
- دسته‌بندی محصولات: نمایش مجموعه‌های مختلف شراب.
- عضویت در خبرنامه: امکان ثبت‌نام برای دریافت اخبار و پیشنهادهای ویژه.
- تورهای تاکستان: معرفی فرایند تولید شراب و تجربه بازدید از تاکستان.
- مقالات جدید: نمایش مطالب مرتبط با شراب، تاریخچه و ترکیب غذا با نوشیدنی.
- منوی ناوبری: دسترسی آسان به بخش‌های اصلی وب‌سایت.
- طراحی واکنش‌گرا: طراحی با هدف ایجاد تجربه کاربری مناسب در مرور صفحات وب‌سایت.
